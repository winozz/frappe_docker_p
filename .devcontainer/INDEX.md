## 🚀 Quick Usage Guide

### Scenario 1: Fresh Start (No frappe_docker yet)

```powershell
# Run the full setup script
cd .devcontainer
.\setup-windows.ps1
```

**What it does:**
1. ✅ Checks prerequisites (Docker, WSL, Git, VS Code)
2. ✅ Clones frappe_docker repository
3. ✅ Copies all CvSU AMS configurations
4. ✅ Creates environment file
5. ✅ Opens VS Code
6. ✅ Shows next steps

### Scenario 2: Already Have frappe_docker

```powershell
# Copy CvSU AMS files to frappe_docker/.devcontainer/
# Then run:
cd frappe_docker
.\apply-cvsu-config.ps1
```

**What it does:**
1. ✅ Checks you're in frappe_docker directory
2. ✅ Creates .devcontainer if missing
3. ✅ Copies docker-compose.cvsu-ais.yml to docker-compose.yml
4. ✅ Backs up existing configuration
5. ✅ Sets up VS Code settings
6. ✅ Optionally opens VS Code

### Scenario 3: Manual Setup

```powershell
# Copy devcontainer configuration
Copy-Item -Recurse -Force "devcontainer-example" ".devcontainer"

# Apply CvSU AMS docker-compose
Copy-Item -Force ".devcontainer\docker-compose.cvsu-ais.yml" ".devcontainer\docker-compose.yml"

# Open in VS Code
code .

# Ctrl+Shift+P → "Dev Containers: Reopen in Container"
```

## 🎯 Workflow After Setup

### 1. Container Build (First Time)
```
Ctrl+Shift+P → "Dev Containers: Reopen in Container"
Wait 5-10 minutes for initial build
```

### 2. Inside Container Setup
```bash
bash /workspace/development/setup-container.sh
```

This will:
- Install Python 3.11.9
- Initialize Frappe bench
- Get ERPNext apps
- Create accounting.localhost site
- Enable developer mode
- Install apps

### 3. Start Development
```bash
cd /workspace/development/frappe-bench
bench start
```

### 4. Access Application
- URL: http://localhost:8000
- Username: Administrator
- Password: admin

### 5. Install Custom Apps
```bash
# Get CvSU HRIS
bench get-app cvsu_hris --branch dev https://github.com/Cavite-State-University-Official/hris.git

# Create AMS app
bench new-app accounting

# Install on site
bench install-app cvsu_hris
bench install-app accounting
```

### ✅ Correct Site Name
- **accounting.localhost** (not cvsu-ais.localhost)
- Matches your workflow and naming convention

### ✅ Correct Apps

### ✅ Developer Mode Enabled

## 🛠️ Customization

### Change Database Password

Edit `docker-compose.cvsu-ais.yml`:
```yaml
environment:
  MYSQL_ROOT_PASSWORD: ${DB_PASSWORD:-your_new_password}
```

### Change Site Name

Edit the startup script in `docker-compose.cvsu-ais.yml`:
```bash
bench new-site your-site-name.localhost \
  --mariadb-root-password 123 \
  --admin-password admin
```

### Add More Apps

Edit the startup script:
```bash
bench get-app your-app --branch version-15
bench install-app your-app
```

### Change Ports

Edit port mappings in `docker-compose.cvsu-ais.yml`:
```yaml
ports:
  - "8080:8000"  # Change 8080 to your preferred port
```
